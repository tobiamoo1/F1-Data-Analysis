# F1-Data-Analysis
The aim of this project is to to practice relational database design and SQL analytics using actual data.

To accomplish this, real F1 data within the "formula_ 1_2025_complete" dataset was used to write queries to answer analytical questions about drivers, constructors, races, and results.

The project also involved designing an Entity–Relationship Diagram (ERD), creating  a relational database schema and 
writing SQL queries using JOIN, GROUP BY, ORDER BY, CASE, and subqueries. This project required thinking critically about multi table relationships and how they enable the creation of an entity relationship diagram and schema. 

The project involved designing an entity relationship diagram based on the Formula 1 dataset, and then creating all the tables required; inputting the tables' keys, constraints, and relationships. This dataset is then loaded into the schema; that is the 'load data local infile.sql' file. 

The SQL analysis questions were then completed using this database design. 


Tools used include: MySQL Database and MySQL Workbench
